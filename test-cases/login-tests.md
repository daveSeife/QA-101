# Login Test Cases

## TC001 - Valid Login
1. Open the login page.
2. Enter a valid email.
3. Enter a valid password.
4. Click Login.

Expected Result:
User should successfully log in.

## TC002 - Invalid Password
1. Open the login page.
2. Enter a valid email.
3. Enter an incorrect password.
4. Click Login.

Expected Result:
An appropriate error message should appear.
## TC003 - Empty Login Fields
1. Open the login page.
2. Leave email and password empty.
3. Click Login.

Expected Result:
Validation messages should appear.

## TC004 - Password Visibility
1. Open the login page.
2. Enter a valid password.
3. Click the password visibility icon.

Expected Result:
Password should become visible.
