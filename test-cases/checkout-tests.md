# Checkout Test Cases

## TC003 - Successful Checkout
1. Add a product to the cart.
2. Proceed to checkout.
3. Enter valid shipping information.
4. Complete payment.

Expected Result:
Order should be successfully placed.

## TC004 - Invalid Payment Details
1. Add a product to the cart.
2. Proceed to checkout.
3. Enter invalid payment details.
4. Submit the order.

Expected Result:
Payment should be rejected and an appropriate error should appear.

## TC005 - Successful Payment
1. Add a product to the cart.
2. Enter valid shipping details.
3. Enter valid payment details.
4. Submit the order.

Expected Result:
Order should be placed successfully.
